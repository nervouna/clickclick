# App Icon Artwork

- `ClickClick/Resources/AppIcon.icon` is the editable Icon Composer source used by the app target.
- `ClickClick/Resources/AppIcon.icon/Assets/app-icon-input-1024.png` is the opaque, unmasked production input.
- Files under `review/` are rendered previews exported from the compiled `AppIcon.icns`.

Do not feed the rendered review PNGs back into Icon Composer or an asset catalog. They already contain the platform mask and are only for visual review.
